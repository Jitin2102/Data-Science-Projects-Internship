**Python and its libraries used in Projects :**  
**1. Numpy**  
***- Provides high-performance array structures (ndarray)***  
***- Supports complex mathematical operations and broadcasting***  
***- Usage: Efficiently computing element-wise operations across large datasets***

***2. Pandas***  
***- Offers powerful data structures like DataFrame and Series***  
***- Used for reading/writing CSVs, cleaning, transforming, and slicing data***  
***- Usage: Converting messy real-world data into clean, structured tables***  

***3. Scikit-Learn***    
***- A go-to library for classical machine learning models and evaluation***  
***- Includes tools for classification, regression, clustering, and preprocessing***  
***- Provides train-test splitting, pipelines***  
***- Usage: Implementing Linear Regression, K-Means, Random Forest, etc***  


***4. Seaborn***  
***- Built on top of Matplotlib, focused on statistical plots***  
***- Offers high-level functions like sns.heatmap, sns.boxplot, sns.pairplot***  
***- Usage: Visualizing student performance using heatmaps or correlations***  

***5. Matplot***  
***- The core library for 2D plotting and basic visualization***  
***- Highly customizable: axes control, text annotations, styles***  
***- Usage: Line charts of predicted vs actual sales over time***  

***6. Plotly***  
***- Creates interactive, zoomable, and hoverable plots for dashboards***  
***- Supports 3D plots, maps, and animations***  
***- Usage: Interactive dashboards for survey or COVID-19 trend data***
