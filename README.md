## 📋 Overview

This repository showcases the data science projects I completed during my internship at **Tamizhan Skills**. Each project demonstrates different aspects of data science, from predictive modeling to data visualization and customer insights.

> **Internship Role:** Data Science and Analytics Intern  
> **Organization:** Tamizhan Skills  
> **Focus:** Machine Learning, Data Analysis, and Business Intelligence

---

## 🎯 Projects Portfolio

### 1. 📈 Sales Forecasting with Linear Regression
**Objective:** Predict future sales trends using historical data

- **Data Processing:** Cleaned and preprocessed historical sales datasets
- **Modeling:** Implemented Linear Regression for trend prediction
- **Visualization:** Created comparative charts showing actual vs predicted sales
- **Business Impact:** Enabled data-driven sales planning and inventory management

### 2. 🎓 Student Performance Analytics Dashboard
**Objective:** Identify at-risk students through comprehensive performance analysis

- **Data Sources:** Student marks, attendance records, engagement metrics
- **Analytics:** Correlation analysis between different performance indicators
- **Visualizations:** Interactive bar charts, heatmaps, and trend analyses
- **Outcome:** Early warning system for academic intervention

### 3. 🎯 Customer Segmentation Using K-Means
**Objective:** Enable targeted marketing through customer behavior analysis

- **Segmentation Criteria:** Age, income, spending patterns
- **Algorithm:** K-Means clustering for customer grouping
- **Visualization:** Multi-dimensional clustering plots and customer profiles
- **Application:** Personalized marketing strategy development

### 4. 🦠 COVID-19 Data Analysis
**Objective:** Track and visualize pandemic trends across countries

- **Data Coverage:** Confirmed cases, recoveries, deaths
- **Analysis:** Cumulative trend analysis and country comparisons
- **Storytelling:** Data-driven narrative of pandemic progression
- **Skills Developed:** Public health data interpretation and visualization
